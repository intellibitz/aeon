# AEON Substrate Topology

* **Current Engine Version**: `v0.1.2022734`

This document defines the structural components and orchestrated meta-layers of the `aeon` substrate.

## 1. Native Components (Tier 0 & 1)

1. **AEON-Alpha**: Microsecond intent classification and deterministic neural reflex engine. (Tier: 0)
2. **GAWD / AMA**: Universal swarm supervisor, multi-agent parallel dispatcher, and governance auditor. (Tier: 1)
3. **GEMI**: Deep reasoning bridge, model scouting, local neural tensor execution, and unified cloud provider racing. (Tier: 2)
4. **GMCP Substrate**: Model Context Protocol JSON-RPC 2.0 protocol interop bus and Meta ToolRegistry executor. (Tier: 1)
5. **AmaDaemon**: Persistent background host ensuring permanent availability and instant background recovery. (Tier: 1)
6. **AeonRuntimeAgent**: Autonomous environment preparation agent responsible for weight provisioning and tool linking. (Tier: 1)

## 2. Meta Components (External Orchestration)

7. **MetaModelSubstrate**: External reasoning models (local GGUF vaults, Candle tensors, and REST cloud API endpoints). (Tier: 2)
8. **MetaMcpServer**: External Model Context Protocol servers connected via stdio or TCP JSON-RPC. (Tier: 1)
9. **MetaExecutablePlugin**: External script plugins and distilled WebAssembly reflex binaries. (Tier: 1)

## 3. Meta Contexts (Dynamic State)

10. **MetaSystemEnvironment**: Dynamic host CPU, RAM, GPU acceleration, and OS hardware profile. (Tier: 0)
11. **MetaUserEnvironment**: Dynamic workspace path, active engine selection, default model substrate, and environment keys. (Tier: 1)
12. **MetaExecutionContext**: Dynamic mission blackboard state, neural checkpoints, session memory, and A2A swarm logs. (Tier: 1)
